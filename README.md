During my trip to Japan I used the camera Panasonic Lumix G80 with 5 different lenses, including 2 Panasonic Leica lenses bought during that trip. I was wondering if on the whole dataset of pictures taken during 18 days there was a difference in ISO or exposure time between old lenses and the new brighter lenses. I extracted data from exif files and the analysis is in file Lenses_graphs_cleaned.html.
